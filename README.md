# ChatGPT Conversation Navigator

ChatGPT 대화 화면에 독립적인 우측 목차 패널을 추가하는 Manifest V3 Chrome 확장 프로그램입니다. 서버나 ChatGPT API를 사용하지 않으며, 현재 브라우저에 렌더링된 메시지 DOM만 읽습니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 프로젝트의 루트 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
5. `https://chatgpt.com/`에서 대화를 열고 새로고침합니다.

## 구조

- `manifest.json`: ChatGPT 도메인에서 순서대로 content script를 로드합니다.
- `src/dom/selectors.js`: 역할·메시지·heading 선택자와 스크롤 컨테이너 탐색을 관리합니다.
- `src/dom/parser.js`: DOM 순서에 따라 user 메시지와 이후 assistant 메시지들을 연결하고 heading 계층을 추출합니다.
- `src/dom/registry.js`: 발견한 질문/제목을 메모리에 보존하고 현재 DOM 탑재 여부를 따로 관리합니다.
- `src/dom/observer.js`: 스트리밍·메시지 추가·SPA 경로 변경을 debounce하여 다시 분석합니다.
- `src/navigation/`: Shadow DOM 패널 렌더링, 이동, 현재 위치 강조를 담당합니다.
- `src/styles/navigation.css`: 패널 전용 스타일(라이트/다크 모드)을 제공합니다.

## 동작과 DOM 가정

역할 속성(`[data-message-author-role]`)을 우선 사용하고, 현재 확인된 ChatGPT 화면에서는 `group/user-message`와 `MarkdownRoot` 구조를 폴백으로 사용합니다. assistant 메시지는 DOM 순서상 가장 최근 user 메시지에 연결됩니다. 따라서 user 메시지 하나에 여러 assistant 메시지가 와도 처리하며, 답변이 아직 없으면 질문만 표시합니다. 제목은 assistant 메시지 내부의 실제 `h1`~`h6`만 사용합니다.

ChatGPT는 SPA이고 DOM을 수시로 바꾸므로, `MutationObserver`가 구조 변경(100ms)과 텍스트 변경(180ms)을 묶어 반영합니다. 한 번 발견한 질문/제목은 해당 대화의 메모리 Registry에 남기고, DOM이 사라지면 이동 불가 상태로 표시합니다. 처음부터 DOM에 없었던 과거 메시지는 수집할 수 없습니다. 다른 대화로 이동하면 Registry와 펼침 상태를 초기화합니다.

## 구현된 기능

- 질문 제목의 생략 표시와 전체 제목 툴팁
- 답변 heading의 레벨별 들여쓰기 및 비정상 heading 순서 처리
- 질문/heading 클릭 시 제목 위에 여유 공간을 둔 즉시 이동, 가상화 레이아웃 변화의 위치 보정, 이동 대상 강조
- 모든 답변의 초기 접기, 질문 아래 개별 펼치기/접기 행, 목차의 독립적인 답변 버튼
- 목차에서 질문/제목을 누르면 해당 답변만 펼친 뒤 이동. ChatGPT 가상화 turn 래퍼는 유지합니다.
- 메시지 내용이 DOM에서 빠졌어도 해당 가상화 turn 래퍼가 남아 있으면 래퍼로 먼저 이동하고 최대 2초 동안 재렌더링을 기다린 뒤 실제 질문/제목으로 이동합니다.
- 하위 제목 목록만 접는 토글, 전체 답변/제목 접기·펼치기, 패널 닫기, 내부 스크롤, 다크 모드
- 패널 드래그 이동과 크기 조절, 현재 읽는 항목 강조
- 스크롤 위치에 따른 활성 항목 표시

## 검증

모든 JavaScript 파일의 구문을 `node --check`로 검사했습니다. `tests/collapse-fixture.html`을 브라우저에서 실행하여 다음을 확인했습니다: 모든 답변 초기 접기, 개별/전체 펼침·접기, 스크롤 후 상태 유지, 목차 클릭 펼침, 스트리밍 제목 추가, 대화 변경 초기화, 30개 동일 질문의 별도 식별, 10개 turn을 DOM에서 제거한 뒤에도 목차 32개 유지, 재삽입 시 연결, 미탑재 항목 이동 불가 안내. 실제 ChatGPT 로그인 화면의 재검증은 다음 절차로 확인해야 합니다.

1. 기존 대화 진입 시 질문과 제목이 즉시 표시되는지 확인합니다.
2. 새 질문과 스트리밍 답변의 제목이 완료 전에도 갱신되는지 확인합니다.
3. 질문·heading 클릭, 직접 스크롤 활성 표시, 다른 대화로 이동을 확인합니다.
4. 라이트/다크 모드, heading 없는 답변, 재생성 답변을 확인합니다.
5. 모든 답변이 접혀 있고 각 답변 위 한 줄 행의 펼치기/접기 버튼이 동작하는지 확인합니다.
6. 예전 질문의 답변이 접힌 상태에서 목차 제목을 눌러 빈 화면이나 스크롤 반동 없이 펼쳐지는지 확인합니다.
7. 펼쳐진 답변의 서로 먼 제목을 연달아 눌러도 최종 위치가 클릭한 제목에 남는지 확인합니다. 직접 휠을 움직이면 자동 보정이 중단되어야 합니다.
8. F07처럼 중간에 있는 제목을 눌러 제목 전체가 화면 상단 아래에 보이는지 확인합니다.

## 알려진 한계

- ChatGPT가 메시지 구조를 변경하면 `src/dom/selectors.js`의 선택자를 갱신해야 합니다.
- 아직 발견되지 않은 가상화된 과거 메시지는 수집할 수 없습니다. 발견 후 메시지 내용이 DOM에서 빠져도 래퍼가 남아 있으면 재탑재를 시도합니다. 래퍼까지 사라졌거나 재탑재가 일어나지 않으면 임의 좌표로 이동하지 않고 실패를 안내합니다.
- 역할 ID가 없는 질문은 내용 지문과 DOM 요소 참조로 식별합니다. 동일한 질문 여러 개가 순서 단서 없이 동시에 가상화·재탑재되면 각각을 확실히 재연결할 수 없고, 편집된 질문은 새 항목으로 보일 수 있습니다. 순서 단서 없는 새 항목에는 “순서 미확인”을 표시합니다.
- 접힘으로 인한 ChatGPT 가상 스크롤의 실제 반응은 사용자 로그인 환경에서 추가 확인이 필요합니다.
- 펼침 상태와 Registry는 해당 탭의 메모리에만 있으며 페이지를 새로고침하면 초기화됩니다. 상태 변경 로그는 페이지 Console에서 `localStorage.setItem('cgn-debug', '1')`로 활성화할 수 있습니다.
- “닫기”는 현재 문서 수명 동안 패널을 제거합니다. 다시 보려면 페이지를 새로고침하거나 확장을 다시 로드하세요.
